📌 Endpoints da API Disponíveis
GET /api/v1/public/consultar/<cpf> Pública / Sem Autenticação

Verifica a existência do cidadão no banco de dados do Cadastro Único com máscara LGPD no nome.

curl -X GET "{{ request.host_url }}api/v1/public/consultar/12345678909"
GET /api/v1/integracao/beneficios/consultar/<cpf_ou_codfam> Requer Token

Retorna a ficha familiar completa (Nome, CPF, Bairro, Código Familiar, Qtd. Membros, Renda Per Capita e Histórico de Atendimentos/Visitas).

curl -X GET "{{ request.host_url }}api/v1/integracao/beneficios/consultar/12345678909" \
  -H "X-SETAS-API-TOKEN: {{ api_token }}"
POST /api/v1/integracao/beneficios/conceder Requer Token

Registra a concessão de um benefício eventual (cesta básica, auxílio funeral, etc.) diretamente na ficha da família no CadÚnico.

curl -X POST "{{ request.host_url }}api/v1/integracao/beneficios/conceder" \
  -H "X-SETAS-API-TOKEN: {{ api_token }}" \
  -H "Content-Type: application/json" \
  -d '{"cpf": "12345678909", "tipo_beneficio": "Cesta Básica Emergencial", "observacao": "Concessão emergencial"}'
