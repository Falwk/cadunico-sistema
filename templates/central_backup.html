ℹ️ Passo a Passo - Integração com a Google Drive API
  1. Criar Pasta no Google Drive: Crie uma pasta chamada Backup Cadastro Único no seu Google Drive.
  2. Criar Projeto no Google Cloud: No Console do Google Cloud, crie o projeto Backup Cadastro Único e ative a Google Drive API.
  3. Conta de Serviço (Service Account): Em Credenciais, crie uma Conta de serviço e baixe a chave em formato .json.
  4. Compartilhar Pasta: Compartilhe a pasta criada no Drive dando permissão de Editor para o e-mail da Conta de Serviço (ex: backup@...iam.gserviceaccount.com).
  5. Configurar no Sistema: Cole o ID da pasta e envie o arquivo credentials.json acima.
